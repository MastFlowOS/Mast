# MAST Instagram Reply Bridge (Chrome Extension)

Passively watches visible unread threads when you open `https://www.instagram.com/direct/inbox/` in Chrome/Edge and notifies your MAST OS workspace when a contacted lead replies—without sharing your Instagram password or needing Meta Business API approval.

## Install (Developer Mode)
1. Open `chrome://extensions` and enable **Developer mode**.
2. Click **Load unpacked** and select `extensions/mast-ig-bridge`.
3. In MAST OS → **Settings** → **Client Reply Observation**, click **Copy Extension Config**.
4. Open the extension popup, paste the config JSON, and click **Save Connection**.
